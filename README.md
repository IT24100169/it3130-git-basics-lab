# IT3130 Git Basics Lab
## Purpose
This repository demonstrates a basic Git workflow for IT3130.
## Files
- HelloWorld.html - a small web page used to practise version control
- README.md - project documentation
## Commands practised
git init, git status, git add, git diff, git commit, git log, git remote, git push
## Technologies

- HTML
- Git
- GitHub

## What I learned
I learned that staging prepares changes before they are committed. Commits save a record of changes in the local repository, while remotes allow the project to be connected and pushed to GitHub.
